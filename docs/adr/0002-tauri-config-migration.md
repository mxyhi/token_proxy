# 离线迁移并保留 Token Proxy 的端口和访问控制

新版默认端口为 9208；环境变量和保存的端口仍优先。旧配置通过显式离线命令写入不存在的新目录，源 JSONC 和 SQLite 保持只读，迁移失败不得破坏可回退的旧实例。Codex 凭据以当前数据库为准，历史文件不充当失败后的替代。

旧版裸模型根据优先级选择上游，新基座以路由组表达回退。因此为每个本地密钥生成符合其作用域的模型路由组及别名，禁用项不参与。迁移开启 requireLocalKey，避免新基座原本对 loopback 的免鉴权语义扩大旧密钥的权限；该开关属于本机配置，恢复或同步不能覆盖它。不能等价转换的策略拒绝迁移，未移植的运行选项写入报告并保留原始配置。
