# Codex 模型目录独立于应用发布

Codex 的模型菜单元数据频繁变化，固定在安装包中会迫使用户反复升级。改为读取本仓库 main 的固定公共 JSON URL，并将同一文件编译为离线回退；仓库维护者控制模型、优先级和完整能力元数据，未知字段原样保留。本地额外模型仅在请求鉴权后追加，不写入公共目录。

采用按请求刷新和内存缓存：首次或过期时一个请求最多等待 3 秒，其他并发读取已有目录；成功缓存 15 分钟、失败退避 1 分钟。校验大小、必要字段和唯一 ID 后才替换，网络失败继续使用上次有效快照。缓存不持久化，因此重启且离线时回到安装包版本。固定 URL 成为已发布客户端的兼容契约，破坏性 schema 变化须通过新客户端发布处理。
